# 🎧 Headphone Shop

A clean and responsive headphone shop website built with HTML, CSS, and JavaScript.

# ✨ Features

- Responsive design
- Modern headphone product showcase
- Mobile navigation
- Search interaction
- Promotional deals
- About section
- Smooth animations
- Swiper slider
- Mobile-friendly layout

# 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Remix Icon
- ScrollReveal
- Swiper.js

# 🎯 Sections

Home
Introduction and main hero section.

Deals
Special offers and promotional information.

About
Information about the headphone brand and its purpose.

Products
Collection of headphones with product names, prices, and images.

Contact
Footer with social links, resources, services, and support.

# 📱 Responsive Design

The website is designed to work across different screen sizes.

- Desktop
- Tablet
- Mobile

The navigation changes to a mobile menu on smaller screens, while the content automatically adjusts to fit different devices.

# 🚀 Getting Started

No installation or build tools are required.

1. Clone the repository

git clone <your-repository-url>

2. Open the project

cd headphone-shop

3. Run

Open "index.html" in your web browser.

That's it.
